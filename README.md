# SupplyTrace / Цепочка поставок

SupplyTrace — учебный Django-проект для анализа участия компаний в публичных закупках по ИНН.

Проект собирает данные из открытых источников, показывает карточку компании, таблицу закупок за последний год, частоту участия юрлиц, интерактивный граф связей и HTML-отчёт.

## Что считается «тендером» в проекте

В интерфейсе мы говорим «тендеры и закупки», но внутри проекта работаем с наблюдаемыми публичными записями о закупках и заключённых контрактах. Для каждой такой записи показываются:

- номер / идентификатор;
- дата заключения;
- дата исполнения, если источник её раскрыл;
- предмет;
- сумма;
- заказчик и его ИНН;
- поставщик / победитель и его ИНН, если они раскрыты;
- статус: открытая или закрытая закупка;
- ссылка на источник.

Закрытые закупки не отбрасываются: если победитель не раскрыт, интерфейс явно показывает `Закрытая закупка`, `Победитель не раскрыт` и `ИНН поставщика отсутствует`.

## Источники данных

Основной рабочий сценарий — ручное обновление из публичных источников:

- ЕИС `zakupki.gov.ru`;
- Портал поставщиков `zakupki.mos.ru`.

Проект не хранит публичные реестры целиком. В локальной базе остаются только компании, найденные закупки/контракты и журнал обновлений по тем ИНН, которые пользователь уже открывал или обновлял.

Дата исполнения есть не у всех записей и не у всех источников. Для ЕИС она подхватывается, когда приходит в CSV-выгрузке; для остальных источников поле остаётся необязательным.

## Что умеет приложение

- искать компанию по ИНН;
- подтягивать свежие публичные данные по кнопке;
- показывать тендеры и закупки за последний год;
- отдельно считать открытые и закрытые закупки;
- показывать, где победитель известен, а где не раскрыт;
- строить частоту участия компаний в закупках и контрактах;
- рисовать интерактивный граф `компания → закупка → победитель`;
- формировать HTML-отчёт по компании;
- импортировать демонстрационные CSV без обязательных новых полей.

## Быстрый запуск на Windows

Из корня проекта:

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
copy .env.example .env
.\.venv\Scripts\python.exe manage.py migrate
.\.venv\Scripts\python.exe manage.py runserver
```

Открыть:

```text
http://127.0.0.1:8000/
```

Если окружение уже создано, обычно достаточно:

```powershell
.\.venv\Scripts\python.exe manage.py runserver
```

## Быстрый запуск на Linux

```bash
python3 -m venv .venv
./.venv/bin/python -m pip install -r requirements.txt
cp .env.example .env
./.venv/bin/python manage.py migrate
./.venv/bin/python manage.py runserver
```

## Настройки

Создайте `.env` из `.env.example`.

Основные параметры:

```env
ZAKUPKI_SYNC_ENABLED=True
ZAKUPKI_MOS_SYNC_ENABLED=True
ZAKUPKI_CONTRACTS_LIMIT=100
ZAKUPKI_CONTRACT_LOOKBACK_DAYS=365
ZAKUPKI_TIMEOUT=25
ZAKUPKI_USER_AGENT=SupplyTrace/1.0
DADATA_TOKEN=
```

`DADATA_TOKEN` необязателен. Если токена нет и реквизиты не удалось получить из закупок, приложение создаст минимальную карточку вида `Компания с ИНН ...`.

## Демо-данные

Для локальной демонстрации без зависимости от доступности внешних сайтов можно импортировать два набора:

```powershell
.\.venv\Scripts\python.exe manage.py import_contracts_csv data\import\contracts_demo.csv
.\.venv\Scripts\python.exe manage.py import_contracts_csv data\import\contracts_eis_demo_mirea_30.csv
```

Linux:

```bash
./.venv/bin/python manage.py import_contracts_csv data/import/contracts_demo.csv
./.venv/bin/python manage.py import_contracts_csv data/import/contracts_eis_demo_mirea_30.csv
```

Колонка `execution_date` в CSV необязательна. Старые CSV без неё продолжают импортироваться.

После импорта удобно открыть:

```text
http://127.0.0.1:8000/company/7729040491/
```

## Обновление из публичных источников

Обычное открытие карточки не делает сетевой запрос к реестрам. Это специально: страница остаётся быстрой и не показывает технические ошибки, если внешний источник временно недоступен.

Чтобы получить свежие данные, используйте кнопку `Найти данные в публичных источниках` или `Обновить данные` в карточке компании.

Для прямой проверки ЕИС можно запустить:

```powershell
.\.venv\Scripts\python.exe manage.py sync_zakupki_contracts 7729040491 --limit 20
```

После ручной синхронизации сохраняются дата обновления, итог и статистика по источникам; они отображаются в карточке компании и HTML-отчёте.
