# SupplyTrace

**SupplyTrace** — Django PoC-платформа для анализа цепочек поставок на основе данных контрактов.

Проект реализует основные требования ТЗ: ввод ИНН, карточку компании, граф цепочки, таблицы контрактов, историю поисков и HTML-отчёт.

## Возможности

- поиск компании по ИНН;
- карточка компании;
- история поисков;
- таблица контрактов;
- граф контрагентов;
- HTML-отчёт;
- получение карточки компании через DaData API;
- импорт демонстрационного набора контрактов из CSV;
- построение цепочки заказчиков и поставщиков на основе локальной базы.

## Стек

- Python
- Django
- SQLite
- HTML / CSS
- JavaScript
- vis-network для графа
- DaData API для поиска компании по ИНН

## Логика текущего PoC

Текущая версия проекта честно разделяет источники данных:

```text

CSV/локальная база -> демонстрационные контракты
